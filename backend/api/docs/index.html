Endpoints Base

GET /api/health Público

Verifica o status da API e a conexão com o banco de dados.

// Resposta de sucesso:
{
  "status": "OK",
  "database": "connected",
  "version": "1.0.0",
  "timestamp": "2024-01-15T10:30:00.000Z"
}

Autenticação

POST /api/register Público

Registra um novo usuário no sistema.

Parâmetro Tipo Obrigatório Descrição
nome string Sim Primeiro nome do usuário
sobrenome string Sim Sobrenome do usuário
email string Sim Email único do usuário
senha string Sim Senha (mínimo 4 caracteres) 
// Requisição:
{
  "nome": "João",
  "sobrenome": "Silva",
  "email": "joao@email.com",
  "senha": "minhaSenha123"
}

// Resposta (201):
{
  "message": "Usuário registrado com sucesso.",
  "id": 1,
  "token": "eyJhbGciOiJIUzI1NiIs..."
}
POST /api/login Público

Autentica um usuário e retorna um token JWT.

// Requisição:
{
  "email": "joao@email.com",
  "senha": "minhaSenha123"
}

// Resposta (200):
{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "nome": "João",
  "sobrenome": "Silva",
  "email": "joao@email.com"
}
POST /api/forgot-password Público

Envia um código de recuperação de senha para o email informado.

// Requisição:
{ "email": "joao@email.com" }

// Resposta (200):
{ "message": "Código de recuperação gerado." }
POST /api/reset-password Público

Redefine a senha usando o código de recuperação.

// Requisição:
{
  "email": "joao@email.com",
  "code": "123456",
  "senha": "novaSenha123"
}

Transações

Todos os endpoints abaixo requerem autenticação (Header: Authorization: Bearer <token>)

POST /api/salvar Autenticado

Cria uma nova transação (entrada ou saída).

{
  "data": "2024-01-15",
  "descricao": "Supermercado",
  "valor": 250.00,
  "entradaSaida": "Saída",
  "categoria": "Alimentação",
  "metodoPagamento": "PIX",
  "observacoes": "Compras da semana"
}
GET /api/listar Autenticado

Lista todas as transações do usuário autenticado.

Query params opcionais:
busca - Busca por descrição
tipo - "Entrada" ou "Saída"
categoria - Filtrar por categoria
metodo - Filtrar por método de pagamento
dataInicio - Data inicial (YYYY-MM-DD)
dataFim - Data final (YYYY-MM-DD)
page - Número da página
limit - Itens por página 

// Exemplo:
GET /api/listar?tipo=Saída&categoria=Alimentação&page=1&limit=20
PUT /api/editar Autenticado

Atualiza uma transação existente.

{
  "id": 1,
  "data": "2024-01-16",
  "descricao": "Supermercado Atualizado",
  "valor": 300.00,
  "entradaSaida": "Saída",
  "categoria": "Alimentação",
  "metodoPagamento": "Débito",
  "observacoes": "Compras completas"
}
DELETE /api/deletar Autenticado

Remove uma ou mais transações.

// corpo:
{ "id": 1 }
// ou para múltiplos:
{ "ids": [1, 2, 3] }
POST /api/importar Autenticado

Importa transações em lote (JSON ou CSV).

{
  "transactions": [
    { "data": "2024-01-15", "descricao": "...", ... },
    { "data": "2024-01-16", "descricao": "...", ... }
  ]
}

Códigos de Erro

Código Status Descrição
200 OK Requisição bem sucedida
201 Created Recurso criado com sucesso
400 Bad Request Parâmetros inválidos
401 Unauthorized Token inválido ou expirado
404 Not Found Recurso não encontrado
500 Server Error Erro interno do servidor
